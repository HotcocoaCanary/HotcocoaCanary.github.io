适用读者：用 Hexo + Butterfly 的人。这一篇给的是能直接拿走用的两个文件，不需要 fork 主题、不需要构建工具、不改一行主题源码。

前几篇讲原理和踩坑，这篇只讲怎么装上。

成果

装完之后，Butterfly 页面上所有的面板都会变成带真实折射的玻璃：导航栏、文章卡片、侧栏、目录、代码块、表格、引用块、搜索框、分页、标签。

不是给某几个元素加 class，是整站统一的材质系统——分六档权重，导航轻、文章卡片重、代码块另有配方。

glass.js 371 距离场 → 位移贴图 → SVG 滤镜，选择器映射，生命周期

第 3 步：给它一个值得折射的背景

这一步不能跳过。

折射的本质是「把背景弄弯」。Butterfly 默认的背景是一块纯色——纯色弯了还是纯色，你会觉得「装了跟没装一样」。

动 transform，不要动 background-position。 后者是绘制属性，改它意味着整个铺满视口的图层每帧重绘，而上面压着几十个 backdrop-filter 面——每次重绘都逼它们重新采样、重跑折射滤镜。我博客上换掉这一条之后，性能问题基本消失了。

位移量必须整除花纹周期。 上面的 40px 网格和 320px 光斑，位移 320px 正好是 8 格和 1 个周期，无缝。写成 300px 每分钟就跳一次。

想要更花哨的（星星、花、蝴蝶那种 Telegram 风格的图案层），做法是把上面 background-image 换成一张平铺的 SVG 线稿贴图，原理一样。

它是怎么工作的

三句话：

  1. CSS 定义参数。每档权重是一组自定义属性——折射强度、折射带宽度、倒角锐度、色散强度。
  2. JS 读参数、生成贴图。用有符号距离场算出每个像素的表面斜率，编码进一张 PNG 的红绿通道。
  3. SVG 执行。feDisplacementMap 按贴图的颜色去弯曲 backdrop。

关键在于贴图按几何缓存。位移贴图只和尺寸、圆角、折射参数有关，和内容无关。所以尺寸相同的卡片共用一张——我博客上 30 个玻璃面，实际只生成 6–10 张贴图。

尺寸还做了 8px 量化，因为栅格里的卡片宽度会有亚像素差异（433.39 vs 433.41），不量化就会各生成一张。

Butterfly 特有的坑

装的过程中会遇到的，都在 CSS 里处理掉了，但值得知道为什么。

① 特异性桥接

Butterfly 用 id 选择器给外壳上样式（#recent-posts .recent-post-item），id 特异性碾压类选择器，所以 .glass 的材质属性会被压掉。

glass.css 里那一大串选择器列表就是干这个的——把材质按同等特异性重述一遍。加了新面板发现”样式没生效”，多半是要往这个列表里补一行。

② transition: all 是个陷阱

Butterfly 有十几处 transition: all .3s。all 会给每一个可动画长属性注册过渡，包括 height、padding、margin、border-width 这些布局属性。

我博客首页量出来是 417 个已注册过渡，其中约 130 个是布局属性。任何无关的样式变化——主题切换、窗口 resize——都会在几十个跑着 backdrop-filter 的面上同时动画布局属性。

桥接块里换成显式四项之后：417 → 152（−64%），布局属性过渡 ~130 → 3（−98%）。

③ Butterfly 会在 DOMContentLoaded 之后改 DOM

它把宽表格包进 .table-wrap、动态构建目录。第一遍扫描时这些元素还不存在，所以 glass.js 里有补扫：

④ pjax

开了 pjax 之后整个内容区会被替换，玻璃标记全没了。glass.js 监听了 pjax:complete / pjax:success 重新打标。

⑤ 代码块为什么单独一档

代码块是最容易做砸的：如果做成深色实心板，它永远不可能像玻璃——浅色文字需要不透明的深底才能读，而不透明就不是玻璃。

glass--dense 的做法是把墨色令牌化：浅色主题下是浅玻璃 + 深字，深色主题下是深玻璃 + 浅字。这样两边都既通透又可读。

另外圆角是 20px 而 Butterfly 原本的纵向内边距只有 10px，首末行会顶在圆弧上，所以内容要往里缩——CSS 里那几条 padding 就是干这个的。

降级

三层，都在 CSS 里：

情况 表现
Chromium 完整折射 + 色散 + 菲涅尔
Safari / Firefox .glass-plain → 加 8px 模糊，保留边缘光和着色
完全没有 backdrop-filter 着色提到 82% 不透明，自己扛对比度
prefers-reduced-transparency 直接不透明
prefers-reduced-motion 关掉过渡

JS 会在 <html> 上打 glass-refract 或 glass-plain，想针对某种情况单独调样式，可以挂在这两个类上。

这一版和我博客上跑的有什么区别

这份是移植版，为了「一个文件、能读懂、好改」做了精简。我博客上跑的完整版多了三样：

  • 性能分级：FPS 滚动均值掉下去会按固定顺序砍效果（色散 → 动画 → 畸变 → 背景动画），而且砍到最低也仍然是玻璃，不会退回毛玻璃
  • 视口预算：IntersectionObserver 把滚出屏幕的面释放掉滤镜、保留着色，归档页 80 篇文章不会同时挂 80 个滤镜
  • 渲染器抽象：三个渲染器实现同一个接口，将来加 WebGL 渲染器不影响别处

这些在第二篇里讲。如果你的页面元素不多，移植版够用。

调试时有个建议：判断视觉效果就截图，判断结构（元素在不在、类加没加、滤镜挂没挂）才用 JS 查。getComputedStyle 回答的是”哪条声明赢了级联”，不是”这个像素最后什么颜色”——一个盖在上面的子元素就能让两者对不上。这个教训在第四篇里有详细的经过。
