给博客做一套液态玻璃（五）：从零手写，一步一步

发表于2026-08-21|更新于2026-08-21|projects
|总字数:5.4k|阅读时长:24分钟|浏览量:

适用读者：完全不需要读过前四篇。只要会写 HTML 和 CSS 就能跟下来。我们从一个空白页面开始，一步一步做出带真实折射的玻璃卡片，每一步都能直接看到效果。

全程只用原生 HTML / CSS / JS，不装任何东西。建议用 Chrome 或 Edge，原因第 4 步会讲。

我们要做什么

先说清楚目标，因为很多人（包括当初的我）会把「玻璃」和「毛玻璃」搞混：

  • 毛玻璃：背景被磨糊了，像浴室的窗户
  • 玻璃：背景是扭曲的，不是糊的，而且扭曲只发生在边缘

区别看一眼就明白：拿起你的手机，看屏幕边缘那圈弧面——底下的东西是被「拉」变形的，不是模糊的。

我们要做的是后者。

第 1 步：准备一个值得折射的背景

这一步最容易被跳过，但它决定了后面所有努力是否白费。

折射的本质是「把背景弄弯」。如果背景是一块纯色，弯了也看不出来——纯色弯曲之后还是纯色。

所以先给页面一个有花纹的背景。新建 index.html：

用浏览器打开，你会看到一张彩色渐变，上面铺着白色细网格。中间那个 .card 现在是完全透明的，看不见。

为什么要网格？ 因为直线被弯曲的时候，肉眼最容易看出来。等下折射生效，你会看到网格线在卡片边缘「拐弯」——那是最直观的验证方式。

为什么让它动？ 静止的画面里，扭曲很容易被当成「本来就长这样」。让网格缓慢漂移之后，线条会穿过玻璃边缘——进去的时候弯，出来的时候直——这个过程比任何静态截图都说明问题。

这里有个细节值得单独说：动画动的是 transform，不是 background-position。

两者视觉效果一样，代价差很多。background-position 是绘制属性，改它意味着整个图层每帧重绘；而这个图层铺满视口、上面还压着一个 backdrop-filter 的卡片，于是每次重绘都会连带逼卡片重新采样背景、重跑折射滤镜。transform 则只走合成器，图层栅格化一次，之后只是移动。

还有一点：位移必须是格子尺寸的整数倍。格子是 32px，所以位移 32px 正好一格，循环重启时接不上缝。如果写成 30px，每 8 秒就会跳一下。

第 3 步：算出「每个像素要偏移多少」

要让边缘扭曲，得先知道两件事：

  1. 这个像素离边缘有多远（越近越扭）
  2. 该往哪个方向偏

3.1 距离：有符号距离场

有个现成的数学工具叫有符号距离场（SDF）：给一个坐标，返回它到形状边界的距离。在内部是负数，在边界是 0，在外部是正数。

第 4 步：把结果画成一张图片

现在到了最巧妙的一步。

我们算出了每个像素的偏移量，但 CSS 没有「按数组偏移像素」这种功能。怎么办？

SVG 有个滤镜叫 feDisplacementMap，它的工作方式是：用一张图片的颜色，去决定另一张图片每个像素从哪里采样。

所以 128 是「不偏移」，比 128 大往一边偏，小往另一边偏。

于是思路变成：把偏移量编码成一张图片的红绿通道，交给 SVG 去执行。

想看看这张贴图长什么样？ 在控制台里执行
document.body.append(Object.assign(new Image(), {src: buildMap(380,240,28,40,30).url}))
你会看到一个灰色的圆角矩形，边缘有一圈彩色的光晕——那就是编码后的偏移量。

第 6 步：加边缘光，让它有厚度

现在有折射了，但还缺一样东西——光。

真玻璃的边缘会亮起来，因为你在那里是擦着表面看过去的，反射率会飙升（叫「菲涅尔效应」）。这一项对「立体感」的贡献极大。

好消息是它不需要滤镜，box-shadow 的 inset 天生就沿着 border-radius 走：

注意前两条的模糊半径不是 0。 这是我当初写错的地方：模糊为 0 的 box-shadow 是一条硬线，绕着四条边跑一圈就是「画出来的边框」，不是光。加上小模糊和负扩散之后，每一条才变成贴着自己那条边的柔和光带。

另外，前两条本质是方向性光照：inset 1px 1px 偏向右下，所以在形状内部只会出现在上边和左边（光从左上打来）。这种不对称正是让它显得立体的原因。

第 7 步：加色散（可选，但很值）

真玻璃在扭曲强烈的地方会有彩边，因为红光和蓝光的折射率不同。这一项加上去，「透明介质」的感觉会强很多——因为纯粹的模糊永远不会产生颜色分离。

做法：把背景用三个略微不同的强度位移三次，然后每一路只保留一个颜色通道，最后加起来。

看那三个颜色矩阵的最后一行：

你可能会想：三路的 alpha 加起来会变成 3，是不是该把红路和蓝路的 alpha 归零？

千万不要。 我这么干过，结果是整个页面所有玻璃都变成纯绿色。

原因是 SVG 滤镜在预乘 alpha空间里运算。alpha = 0 意味着这一路的颜色在相加之前就已经被乘成 0 了——红色和蓝色被彻底删除，只剩中间那路绿色。

保留 alpha 才是对的：背景不透明，三个 alpha 相加得 3，然后被自动截断回 1，既正确又无害。

改这几个数字，观感差别很大：

参数 作用 试试
bezel 折射带有多宽 改成 15（薄玻璃）或 80（厚玻璃）
