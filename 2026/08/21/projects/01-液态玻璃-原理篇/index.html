给博客做一套液态玻璃（一）：玻璃到底是什么

发表于2026-08-21|更新于2026-08-21|projects
|总字数:1.8k|阅读时长:5分钟|浏览量:

适用读者：想在网页上做出「真玻璃」质感的前端开发者。本篇不写代码，只讲清楚一件事——为什么 backdrop-filter: blur() 做不出玻璃。

从一个失败的起点说起

想在网页上做玻璃，几乎所有教程都会给你这三行：

这套东西做出来的是毛玻璃（frosted glass），不是玻璃。区别在哪？

去找一块真的玻璃，比如手机屏幕的边缘、一个玻璃杯的杯壁。你会发现：

  • 玻璃中间几乎是完全透明的，不模糊
  • 所有的「玻璃感」都集中在边缘：那里的背景是扭曲的，不是模糊的
  • 边缘还会有一圈亮边，越接近边缘越亮
  • 仔细看，扭曲的地方带一点彩边

上面那三行 CSS 里，没有一条在描述这四件事。blur() 描述的是「隔着一层磨砂」，而不是「隔着一块透明的、有厚度的介质」。

模糊是浴室玻璃，扭曲才是眼镜片。

玻璃的四个光学分量

要在网页上重建玻璃，得先知道要重建什么。拆开来是四个独立的分量。

① 折射（Refraction）

光从空气进入玻璃时会拐弯，拐多少由折射率（Index of Refraction，IOR）决定。普通光学玻璃的 IOR 在 1.45–1.52 之间。

但关键不在 IOR 这个数字，而在表面的斜率：

一块两面平行的玻璃板，正着看几乎没有畸变——因为光进去拐一次、出来拐回来，抵消了。只有表面弯曲的地方，光才会净偏折。

这解释了本文开头那个观察：玻璃的中间是平的，所以透明；边缘是圆弧倒角，所以扭曲。

推论：想让一个 div 看起来像玻璃，我们要计算的不是「模糊多少」，而是「每个像素处的表面斜率是多少」。

② 色散（Chromatic Aberration）

折射率对不同波长的光是不一样的——红光偏折少，蓝光偏折多。所以在畸变强烈的地方，会出现彩色的边：

这就是为什么廉价放大镜的边缘会有彩虹边。它在视觉上是「这是一块真的透明介质」的强信号——因为纯粹的模糊永远不会产生颜色分离。

③ 菲涅尔反射（Fresnel）

这是最容易被忽略、但对「立体感」贡献最大的一项。

你看一个表面的角度越斜，它就越像镜子。 站在湖边低头看，能看见水底；望向远处的湖面，看到的是天空的倒影。同一片水，只是视角不同。

在一块有倒角的玻璃上，倒角处的表面是斜的，你几乎是擦着它看过去的，于是那一圈的反射率飙升——整个轮廓会亮起来，并向内衰减。

我参考的那个 WebGL 实现（ybouane/liquidglass）里，fresnel 的默认权重是 1.00，是所有光学参数里最高的。而我最初的实现里，这一项完全没有。加上它之后，「厚度」是肉眼可见地出现的。

④ 高光（Specular）

点光源在弯曲表面上的镜面反射。这一项相对次要，而且 CSS 的 box-shadow inset 本来就能近似——但有个前提，后面会讲。

关键洞察：边缘形状 = 距离场

现在问题变成了：怎么算出每个像素处的表面斜率？

如果玻璃是个圆角矩形，那它的倒角在哪、朝哪个方向弯，完全由「这个像素离最近的边有多远」决定。

  1. 方向：距离场的梯度就是表面法线——光该往哪个方向偏

问题出在 smoothstep 是 S 形曲线，它两端的导数都是零——包括边缘那一端。而折射跟随的是斜率。一个在边缘处斜率归零的剖面，描述的是这个东西：

平切角（chamfer），不是圆角（fillet）。 难怪它看起来像被刀切过。

改成圆弧截面：

$$t(u) = u \sqrt{\frac{1-K}{1-u^2K}}$$

其中 u 从带内侧的 0 到边缘的 1。端点值不变（t(0)=0、t(1)=1），但边缘处的斜率从 0 变成了 1 + K/(1-K)。实测三档权重下，边缘斜率从 6.12e-6 提升到 4.48e-2，约 7000 倍。

这里还有个陷阱：u 必须线性取自距离，不能再套一层 smoothstep。链式法则会把那个零斜率原样送回边缘，整个改动就白做了。

为什么不用 WebGL

到这一步，很自然的想法是「上 WebGL 写 shader 吧」。我没有，原因是场景不匹配：

一篇文章页上有 30 个玻璃面——卡片、侧栏、导航、代码块、表格、引用块。如果每一个都跑一个 WebGL context：

浏览器对同时存在的 WebGL context 数量有硬限制（通常 8–16 个），超了会开始丢弃最老的。而且这些面在滚动时会不断进出视口。

更重要的是：这些面是静态的。卡片不会自己动，背景才动。为一个不变的形状每帧重跑 shader，是纯粹的浪费。

所以路线定在：SVG feDisplacementMap。位移贴图按几何尺寸生成一次、缓存复用，浏览器自己合成。代价是拿不到实时的 shader 效果，收益是 30 个面的成本约等于 6–10 张贴图。

下一篇讲这套东西怎么落地成一个能用的系统。

小结

你以为的玻璃 实际的玻璃
blur() 中间不模糊，边缘扭曲
一条 border 一圈由内向外衰减的菲涅尔辉光
均匀的效果 全部集中在倒角那几十个像素里
纯灰度 畸变处有色散彩边

一句话：做玻璃不是做模糊，是做一个表面斜率场。
